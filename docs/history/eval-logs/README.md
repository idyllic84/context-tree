# Original evaluation logs are not included

The original development directory contained JSON outputs derived from private sessions. Those files are not part of this standalone repository. They may contain full user/assistant content, local paths, source identifiers and model outputs.

References to this directory in historical documents describe past experiments, not bundled reproducible artifacts. Missing raw sessions and logs mean those experiments cannot be independently reconstructed from this repository alone.

Use the synthetic, per-stage fixtures under `src/context_tree/stages/*/evaluate.py` and follow [the current evaluation guide](../../evaluation.md). Save new online results to an ignored local artifacts directory, review them for sensitive content, and obtain authorization before sharing.
